How this works

This tool finds specific pieces of text in your documents and assembles them into one summary, noting where each piece came from. It follows fixed rules you define — no AI, no internet, and no file leaves this computer.

1 · RulesetSay what to extract and where to find it.
2 · Output templateSay how the summary is laid out.
3 · Add filesDrop in the documents, or load the samples.
4 · ExtractReview, and the files download themselves.

Extraction methods by file type

MethodWhat it findsAvailable for
Between Everything between two anchors. Returns plain text if both anchors sit on the same line, or the whole span including tables if they're further apart. Word, PDF, PowerPoint
Right of (table cell) The table cell immediately right of a label cell. Works inside tables only. Word, PDF, PowerPoint
Around keywords The paragraph or table containing a word or phrase. If the keyword is inside a table, the whole table is returned; if in a paragraph, that paragraph plus any neighbouring paragraphs you ask for. All formats
Table contains The entire table containing a phrase. Excel only
Sheet cell One spreadsheet cell, or a range of cells selected by dragging. Excel only

Only the methods that can work on the chosen file are offered.

Picking anchors

Once you choose a file, a preview appears inside the field. Select text in it and click Set as start anchor (or end, label, keyword). Clicking the same button again unsets it. Chosen anchors stay highlighted in the preview in matching colours.

Headings light up when you hover them — click once to take the whole heading, or drag across the text to take part of it.

For spreadsheets, click a cell, or click and drag to select a rectangular range.

Anchor text is matched loosely: capitals, dashes, curly quotes, extra spaces and a trailing * are forgiven.

Where your files are kept

Everything stays on this computer, in the workspace folder next to the program: uploaded files, saved rulesets and output templates, and every past run. Nothing is sent anywhere.

Uploaded files build up a local library, so documents you added before are still there next time. Pick which ones a run should use from Previously uploaded files. Remove selected deletes individual files; Clear all files empties the library.

Which files work best

FormatNotes
Word .docxBest — real table structure, so cell rules are exact.
Excel .xlsxBest — exact cell addressing.
PowerPoint .pptxGood — includes speaker notes.
PDF .pdfLeast reliable — PDFs have no real tables, so table rules are approximate.
